# 文字修仙 · 游戏设计方案

> 定位：减法向、纯文字、真实困难的修仙养成游戏
> 平台：抖音互动空间
> 核心理念：让玩家「真的在修」，而非「假装在修」

---

## 一、设计哲学

### 1.1 核心原则：做减法

- 不追求系统丰富，追求每一秒注意力只落在一件事上
- 没有战斗操作、没有复杂数值面板、没有十几个子系统
- 核心循环就是「攒 → 投 → 等 → 收获」
- 文字是精炼的氛围，不是小说

### 1.2 与同类产品的差异化

| 同类修仙游戏的坑  | 本游戏的做法                     |
| ----------------- | -------------------------------- |
| 战斗动画/特效堆砌 | 纯文字叙事，画面留给想象力       |
| 10+ 属性面板      | 仅保留 5 条核心属性              |
| 5+ 种货币         | 仅 1 种货币（灵石）              |
| 开局全开放子系统  | 随境界逐步解锁                   |
| 大段剧情文字      | 精炼的事件文案                   |
| 挂机爽游          | 真实时间压力，不认真修就真的会死 |

### 1.3 目标受众

- 核心受众：30-45 岁中年男性（修仙小说主要读者，有消费能力）
- 能 get 到「时间不够用」的代入感
- 定位为「少数人深爱」的作品，不追求大众留存

## 二、世界观与版权

### 2.1 版权策略

- 采用**修仙公共框架**，不使用任何具体 IP 的角色名、剧情、专有名词
- 安全使用的公共素材：

| 类别     | 可安全使用的内容                               |
| -------- | ---------------------------------------------- |
| 境界名称 | 练气、筑基、金丹、元婴、化神（修仙类型通用词） |
| 资源名称 | 灵石、丹药、功法、法宝、灵根、妖兽（通用词）   |
| 机制概念 | 闭关、突破、渡劫、寿元、走火入魔（通用机制）   |

- 需要避开的：

| 类别         | 示例               | 原因                     |
| ------------ | ------------------ | ------------------------ |
| 具体角色名   | 韩立、南宫婉       | 凡人修仙传独创角色       |
| 具体功法名   | 青元剑诀           | 凡人修仙传独创           |
| 具体地名     | 黄枫谷、乱星海     | 凡人修仙传独创           |
| 斗罗专有名词 | 武魂、魂环、魂骨   | 唐家三少独创，辨识度极高 |
| 斗破专有名词 | 斗气、异火、炼药师 | 有辨识度                 |

### 2.2 后续可选方向

如果未来想加入斗罗/斗破的成长结构，采用「借结构不借名词」的方式：

- 魂环颜色分级 → 境界品阶（凡/灵/仙/神品）
- 猎杀魂兽 → 斩杀妖兽取内丹
- 双生武魂 → 双灵根/双天赋
- 魂骨 → 本命法宝

## 三、境界体系

### 3.1 大境界（5 阶，第一阶段封顶化神）

| 大境界 | 小阶段          | 寿命    | 真实时间(1天=2年) | 说明                         |
| ------ | --------------- | ------- | ----------------- | ---------------------------- |
| 练气期 | 1-9 层          | 80 年   | 40 天             | 入门，最脆弱，凡人一刀能砍死 |
| 筑基期 | 初/中/后/大圆满 | 200 年  | 100 天            | 真正踏入修仙，第一次延寿     |
| 金丹期 | 初/中/后/大圆满 | 500 年  | 250 天            | 体内结丹，可御剑飞行         |
| 元婴期 | 初/中/后/大圆满 | 1000 年 | 500 天            | 金丹化婴，元神出窍           |
| 化神期 | 初/中/后/大圆满 | 2000 年 | 1000 天           | 当前版本人界天花板           |

### 3.2 设计要点

- 练气期用 9 层（前期成长感密集，让新手快速体验升级爽感）
- 后续境界统一用初/中/后/大圆满（全局统一，减法）
- 越高境界，冥想效率越低，逼玩家使用闭关
- 共 5 大境界 × 4 小阶段 = 20 个成长节点（练气 9 层 + 筑基至化神各 4 阶 = 25 节点）

## 四、时间系统

### 4.1 时间压缩比

**核心设定：1 天真实时间 = 2 年游戏内时间**

| 真实时间 | 游戏内时间 | 说明                             |
| -------- | ---------- | -------------------------------- |
| 1 天     | 2 年       | 基础单位                         |
| 10 天    | 20 年      |                                  |
| 32 天    | 64 年      | 练气期（16岁起）到突破筑基的极限 |
| 40 天    | 80 年      | 凡人完整寿命                     |
| 50 天    | 100 年     | 筑基寿命                         |
| 250 天   | 500 年     | 金丹寿命                         |

### 4.2 离线时间处理

- **离线时间照常流逝**，玩家不登录也会增加游戏内年龄
- 寿元耗尽时会在下次读取状态时判定死亡
- 离线结算由后端按最后更新时间统一完成，前端倒计时只负责展示

### 4.3 各活动时间消耗

| 活动             | 真实时间     | 游戏内时间 | 说明                       |
| ---------------- | ------------ | ---------- | -------------------------- |
| 感悟             | 瞬间（连点） | —          | 碎片时间，即时微收益       |
| 冥想             | 3 分钟       | —          | 日常积累，定期反馈         |
| 深度冥想（可选） | 20 分钟      | —          | 更高收益，给时间充裕的玩家 |
| 闭关             | 24-48 小时   | 2-4 年     | 长周期大额收益             |
| 渡劫             | 瞬间结算     | —          | 突破时一次性判定           |

## 五、核心玩法循环

### 5.1 核心循环图

```
日常：感悟(瞬间) / 冥想(3分钟) → 攒修为 + 攒资源
              ↓
每周：准备闭关(选心法+法阵+丹药) → 闭关24-48小时 → 大额修为
              ↓
突破：修为满了 → 渡劫(可能失败) → 进入下一境界
              ↓
每周/月：遗迹探索 / 宗门争锋 → 获得稀有资源
```

### 5.2 冥想系统

- 基础玩法：每次 3 分钟，获得少量修为
- 解锁机制：到一定等级解锁「冥想 10 次」（批量操作，减少重复点击）
- 深度冥想（可选）：20 分钟，收益更高
- 越高境界，冥想效率越低（逼玩家转向闭关）

### 5.2.1 感悟（即时微收益）

- 点击「感悟」后本地累计 1 次，不立即请求接口
- 累计 5 次后，五个亮点合并并飞入修为区域，再向后端提交一次批次结算
- 后端只接受完整批次，按点击次数计算收益并记录每日次数
- 感悟为即时动作，不改变当前状态，可与冥想、闭关、探索并行
- 点击响应间隔、批次大小、每日上限与冷却全部由 `config/meditation.json` 控制

### 5.3 闭关系统

- 长周期玩法：24-48 小时真实时间
- 需要提前准备资源：心法 + 法阵 + 丹药
- 闭关面板设计（简单 buff 叠加，不搞复杂拼图）：

```
闭关中
心法: 《吐纳术》   效率 100%
阵法: 聚灵阵(小)   +20%
丹药: 培元丹 x3    +30%

预计闭关收益: 修为 +5000
是否开始闭关？(48小时)
```

- 闭关风险：走火入魔，修为倒退

### 5.4 法阵系统

- 简单 buff 叠加，不做阵法拼图
- 玩家选好心法 + 法阵 + 丹药，点开始，然后等
- 不同法阵提供不同增益（聚灵阵加修为、护神阵防走火入魔等）

### 5.5 渡劫（境界突破）

- 修为满了 + 满足条件后触发
- 一次性判定，可能失败
- 失败后果：重伤、修为倒退、寿元减少
- 成功：进入下一境界，寿命大幅延长

### 5.6 修炼反馈与庆祝效果

每一次修炼收获都要有「仪式感」，避免结算时页面太平淡、毫无反馈。为此设立一套**可复用的庆祝模块**，按收获轻重分三档规格，供冥想、闭关以及后续渡劫、遗迹大丰收等所有玩法统一调用。

| 规格             | 触发场景     | 情绪目标                               |
| ---------------- | ------------ | -------------------------------------- |
| 基础（basic）    | 普通冥想结束 | 轻量恭喜，制造「日日精进」的日常爽感   |
| 进阶（advanced） | 深度冥想结束 | 更强的成就感，奖励翻倍的兑现感         |
| 盛大（grand）    | 闭关结束     | 长周期等待后的爆发式奖励，最高规格仪式 |

三级共同要点：

- 弹层出现后短暂停留、自动消散，也可点击空白处关闭，不打断操作节奏
- 视觉统一走「暗色复古 + 绿色灵光」风：中央祝词 + 浮动灵光粒子 + 渐强光晕，规格越高粒子越多、光晕越亮、停留越久
- 文案示例（可在代码中按需润色）：

```
基础：修炼有成 · 心静如水，气息绵长 · 修为 +N
进阶：深修有得 · 入定深境，灵光乍现 · 修为 +N
盛大：闭关大成 · 闭关圆满，道行大进 · 修为 +N · 灵台清明，道基愈发稳固
```

技术实现约束：

- 做成**全局单例模块**（挂载一次，任意玩法调用 `celebrate(规格, 文案)`），后续渡劫成功、突破、遗迹大丰收等直接复用，无需重复造轮子
- 纯 CSS/SVG 动画，**不引入任何外部动效库**（遵守「不新增依赖」红线）
- 庆祝属于表现层反馈，不影响任何数值结算；数值仍以后端返回为准

## 六、角色属性

### 6.1 第一版属性面板（仅 5 条）

```
━━━━━━━━━━━━━━
道号: 无名散修
境界: 练气三层
寿元: 25/80 年
修为: 340/1000
气血: 100/100
灵石: 230
━━━━━━━━━━━━━━
```

| 属性 | 服务玩法               | 说明                         |
| ---- | ---------------------- | ---------------------------- |
| 境界 | 全局                   | 当前修为等级                 |
| 寿元 | 全局                   | 寿命，用完就死，核心压力机制 |
| 修为 | 冥想、闭关、突破       | 成长进度指标                 |
| 气血 | 遗迹探索受伤、渡劫失败 | 受伤影响修炼效率             |
| 灵石 | 买丹药、法阵材料       | 基础货币                     |

### 6.2 气血（血条）的使用方式

- 遗迹探索、渡劫失败会导致受伤
- 受伤状态影响修炼效率：`气血 80/100 (轻伤，修炼效率 -20%)`
- 需要吃丹药回血或休息恢复
- **如果不做受伤机制，则删掉血条**

### 6.3 不做的属性

| 属性          | 什么时候加         |
| ------------- | ------------------ |
| 灵力/法力     | 做战斗或技能系统时 |
| 攻击力/防御力 | 做战斗系统时       |
| 悟性/资质     | 做功法学习差异时   |
| 声望/罪孽     | 做宗门/善恶系统时  |
| 法宝战力      | 做装备系统时       |

### 6.4 属性设计原则

**属性的价值 = 它影响了多少个玩法决策**

- 只做价值 > 0 的属性
- 不为还不存在的玩法设计属性
- 没有战斗系统，就不做攻防属性

## 七、真实年龄系统

### 7.1 方案：真实年龄 + 悟性补偿

使用身份证获取真实年龄（通过官方实名认证接口，不存储原始身份证号），不同年龄开局有不同属性：

| 真实年龄 | 初始游戏年龄 | 悟性 | 初始灵石 | 续命丹 | 策略定位           |
| -------- | ------------ | ---- | -------- | ------ | ------------------ |
| 16 岁    | 16 岁        | 100% | 0        | 0      | 标准开局，慢慢熬   |
| 25 岁    | 25 岁        | 110% | 500      | 0      | 略有优势           |
| 40 岁    | 40 岁        | 125% | 2000     | 2      | 时间紧但效率高     |
| 60 岁    | 60 岁        | 150% | 5000     | 5      | 背水一战，速成路线 |

### 7.2 设计逻辑

- 年纪大 = 时间少，但阅历深、悟性高、资源多
- 不是「被补偿的弱者」，而是「有阅历的修士」
- 不同年龄 = 不同玩法策略，各有优劣，没有不公平
- 修仙小说常见「年老入道但厚积薄发」的设定

### 7.3 实名认证技术要求

- 通过官方授权的实名认证接口（如字节的或第三方有资质的）
- 接口只返回「是否实名 + 出生年份（或年龄）」
- **不收集、不存储原始身份证号**
- 未成年用户需特殊处理（防沉迷系统限制 + 寿元机制调整）

## 八、死亡与转世系统

### 8.1 死亡方式

| 死亡方式 | 触发条件               | 能否避免           |
| -------- | ---------------------- | ------------------ |
| 自然死亡 | 寿元耗尽，未突破       | 可通过突破延寿避免 |
| 兵解转世 | 玩家主动选择           | 玩家自愿           |
| 遗迹死亡 | 遗迹探索中遇难         | 可用复活道具       |
| 渡劫身亡 | 突破渡劫失败（小概率） | 可用道具降低风险   |

### 8.2 续命机制

- 突破失败但快死时，可吃延寿丹续命
- **效果递减**：

| 次数    | 续命效果 |
| ------- | -------- |
| 第 1 次 | +10 年   |
| 第 2 次 | +5 年    |
| 第 3 次 | +2 年    |
| 第 4 次 | +1 年    |
| 第 5 次 | 无效     |

- 续命丹药昂贵，逼玩家在「继续苟」和「转世重修」之间做选择

### 8.3 复活道具

- 替死符 / 复活卷轴
- 仅在遗迹探索中死亡时可用
- 没有道具就真死了
- 高风险高回报玩法，玩家自己掂量

### 8.4 转世重修

死亡后可以转世重修，保留有限传承（roguelike 式成长）：

```
你寿元已尽，化作一抔黄土。

转世继承：
- 前世修为感悟: 修炼速度 +15%
- 前世功法记忆: 可继承一部功法
- 前世灵石: 保留 10%

是否转世重修？
[是]  [结束游戏]
```

### 8.5 死亡体验设计要点

- 死亡要有仪式感：做一段煽情文字回顾，让玩家觉得这一生值了
- 转世要给希望：让玩家相信「下一世能走得更远」
- 前期要友好：练气期给足引导，让玩家在「快死」之前至少突破一次，体验延寿的爽

## 九、周期性玩法

### 9.1 遗迹探索（每周/每月一次）

- 不做复杂副本，做成文字冒险
- 随机事件 + 选择分支：

```
你进入上古遗迹，发现三条路——
[左侧] 隐约有丹香
[中间] 隐约有剑鸣
[右侧] 隐约有血腥味
```

- 选择后随机触发事件：可能获得丹药/功法/材料，也可能受伤或死
- 可使用替死符/复活卷轴

### 9.2 宗门争锋（定期活动）

- 不用「屠杀」等负面词汇，改为「宗门争锋」或「秘境争夺」
- 可做成异步 PvP：抢别人灵脉，别人也能抢你的
- 增加社交互动

## 十、战斗系统（暂不做）

### 10.1 设计理念

- 第一版不做战斗系统
- 战斗 = 数值结算 + 文字叙事
- 胜负由修为境界决定，不需要操作

### 10.2 文字战斗示例

```
你潜入妖兽森林深处，一头幽冥虎挡住去路。

它的修为约 3200 年，气息森寒。
你深吸一口气，武魂附体——

[你的修为: 38级] vs [妖兽年限: 3200年]

经过一番苦战，你斩杀幽冥虎，
获得妖兽内丹一枚。
```

### 10.3 抉择代替操作

如果纯数值结算太单调，可加文字选择题：

```
幽冥虎临死反扑，你选择——
[硬抗一击] 可能受伤，但能拿到完整内丹
[闪避撤退] 安全，但内丹可能消散
```

## 十一、修仙常识速查

### 11.1 境界体系（公共框架）

```
练气 → 筑基 → 金丹 → 元婴 → 化神（当前版本封顶）
```

- 练气期：刚入门，最脆弱，凡人一刀能砍死
- 筑基：寿命延长到 200 岁，真正踏入修仙
- 金丹：体内结丹，寿命 500 岁，可御剑飞行
- 元婴：金丹化婴，寿命 1000 岁，元神出窍
- 化神：当前版本最高境界，后续境界暂未开放

### 11.2 核心资源

| 资源      | 作用                     | 游戏内对应     |
| --------- | ------------------------ | -------------- |
| 灵石      | 通用货币                 | 货币           |
| 丹药      | 加速修炼、突破、疗伤     | 闭关增益、续命 |
| 灵草/灵矿 | 炼丹炼器材料             | 法阵材料       |
| 功法      | 修炼方法，决定效率和上限 | 闭关心法       |
| 法宝      | 武器装备                 | 后期系统       |
| 寿元      | 寿命，用完就死           | 核心压力机制   |

### 11.3 核心活动

| 活动      | 干的事           | 风险           |
| --------- | ---------------- | -------------- |
| 打坐/冥想 | 慢慢涨修为       | 无风险，慢     |
| 闭关      | 长时间高强度修炼 | 走火入魔       |
