# 文字修仙 · 数值系统设计（V1 基线版）

> 本表为第一版基线数值，所有参数均可调。
> 设计锚点：**练气期 ≈ 32 天真实时间必须突破筑基，否则死亡**，其余数值由此倒推。

---

## 一、总纲：节奏目标

| 境界阶段 | 目标真实用时 | 设计意图                         |
| -------- | ------------ | -------------------------------- |
| 练气期   | 20-32 天     | 前期有压力、能快速升级尝到爽感   |
| 筑基期   | 40-60 天     | 第一次延寿，喘口气，节奏适度放慢 |
| 金丹期   | 60-90 天     | 中期目标，开始依赖闭关           |
| 元婴期   | 90-150 天    | 后期，闭关为主力                 |
| 化神期   | 150+ 天      | 当前版本人界天花板               |

核心原则：**越往后越慢、越依赖闭关和资源**，而不是单纯堆时间。

---

## 二、时间系统（已知，纳入数值）

- 压缩比：**1 天真实时间 = 2 年游戏内时间**（1 游戏年 = 12 真实小时）
- 离线：寿元照常流逝，离线期间也在计算游戏内年龄与死亡

寿命换算：

| 境界 | 寿命    | 真实时间 |
| ---- | ------- | -------- |
| 凡人 | 80 年   | 40 天    |
| 练气 | 80 年   | 40 天    |
| 筑基 | 200 年  | 100 天   |
| 金丹 | 500 年  | 250 天   |
| 元婴 | 1000 年 | 500 天   |
| 化神 | 2000 年 | 1000 天  |

16 岁开局，练气期突破窗口 = (80-16) = 64 年 = 32 真实天。

## 四、修为获取

### 4.1 悟道（即时微收益）

- 单次悟道（练气基准）：2 修为
- 每 5 次悟道结算一次，即一批 10 修为
- 收益公式：`dazuo_base_exp × 点击次数 × 境界效率 × 年龄补偿 × 转世加成`
- 每日上限按点击次数统计，当前配置为 300 次；点击间隔当前配置为 100ms

### 4.2 冥想（定期积累）

| 时长               | 修为（练气基准） | 说明             |
| ------------------ | ---------------- | ---------------- |
| 180 秒             | 30               | 标准冥想         |
| 1200 秒（深度冥想）| 200              | 更高收益，鼓励沉浸 |

修为公式：`基础值 × meditation_exp_ratio × 境界效率系数 × 年龄补偿 × 转世加成`

### 4.3 境界效率系数（逼玩家后期转闭关）

| 境界 | 系数 |
| ---- | ---- |
| 练气 | 1.0  |
| 筑基 | 0.8  |
| 金丹 | 0.5  |
| 元婴 | 0.3  |
| 化神 | 0.2  |

### 4.4 节奏校验（练气期）

- 练气累计需 7565 修为
- 每次冥想 30 修为（180秒），约需 253 次
- 32 天踏线突破 = 每天约 8 次 = 每天约 24 分钟
- 结论：冥想负责定期投入，悟道补充碎片时间收益，偷懒仍会面临死亡压力 ✅

### 4.5 闭关（中后期主力）

公式：`产出 = 闭关基础值 × 境界系数 × (1 + 法阵加成 + 丹药加成)`

| 闭关时长 | 练气基准产出 |
| -------- | ------------ |
| 24 小时  | 2500         |
| 48 小时  | 5000         |

> 闭关需要灵石准备（丹药+法阵材料），是「策略投入」，不是免费躺拿。

## 九、气血与受伤

- 气血上限：100（各境界通用，V1 不做成长）
- 受伤来源：渡劫失败、遗迹探索踩坑
- 受伤影响：`气血 < 80 → 修炼效率 -20%`，`气血 < 50 → 再 -20%`
- 恢复：回春丹 +30 / 休息（登录离线恢复，速率 10/天）

## 十二、寿命、死亡与转世

### 12.1 延寿丹（续命，效果递减）

| 次数    | 续命效果 |
| ------- | -------- |
| 第 1 次 | +10 年   |
| 第 2 次 | +5 年    |
| 第 3 次 | +2 年    |
| 第 4 次 | +1 年    |
| 第 5 次 | 无效     |

价格递增：5000 / 10000 / 20000 / 40000 灵石。

### 12.2 转世传承（死亡后重开）

| 传承项       | 比例                   |
| ------------ | ---------------------- |
| 修炼速度感悟 | +15%（可叠加到下一代） |
| 功法记忆     | 继承 1 部功法          |
| 灵石         | 保留 10%               |

> 传承可累积，鼓励「多世修行」的 roguelike 成长，死亡不是终点。

## 十三、真实年龄补偿（绑定实名年龄）

| 真实年龄 | 悟性（修炼效率） | 初始灵石 | 延寿丹 |
| -------- | ---------------- | -------- | ------ |
| 16 岁    | 100%             | 0        | 0      |
| 25 岁    | 110%             | 500      | 0      |
| 40 岁    | 125%             | 2000     | 2      |
| 60 岁    | 150%             | 5000     | 5      |

实际年龄取「不超过该年龄的最高预设档位」：12-24 岁按 16 岁档，25-39 岁按 25 岁档，40-59 岁按 40 岁档，60 岁及以上按 60 岁档。

> 年龄越大 = 时间少但效率高、资源多，形成不同策略而非单纯劣势。
